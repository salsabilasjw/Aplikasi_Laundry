Judul Projek : Aplikasi Laundry

Aplikasi ini membantu pengelolaan layanan laundry agar lebih efisien. Pengguna dapat memasukkan 
data pelanggan, berat cucian, dan memilih jenis layanan. Sistem akan menghitung biaya serta 
menampilkan status cucian, sehingga proses menjadi lebih cepat, akurat, dan terorganisir.
